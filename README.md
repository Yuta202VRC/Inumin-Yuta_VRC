# ToN Web Manager

**Terrors of Nowhere のラウンド情報・戦績・テラー攻略メモを、ブラウザーでまとめて確認できるツールです。**

ゲーム連携アプリから受け取った情報をもとに、現在のラウンド、出現テラー、生存記録、特殊イベントの状況を表示します。個人での記録に加え、部屋を作って他の利用者と情報を共有できます。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| ラウンド情報 | ラウンド種別・出現テラー・接続状態を表示 |
| 戦績の記録 | 試合回数、生存回数、生存率、現在・最高連勝を表示 |
| ラウンド履歴 | 全ラウンドと特殊ラウンドの履歴をそれぞれ保存 |
| テラー別の統計 | 遭遇回数・生存率を検索、並べ替え |
| 特殊イベントの確認 | Moonの解放状態と鳥3種の出現状況をランプで表示 |
| 個人メモ | テラーごとの攻略メモ、危険度、スタン・実績・即死攻撃の情報を保存 |
| Wikiリンク | 名前の表記ゆれに対応したリンクと、テラーごとのURL指定 |
| マルチプレイ連携 | 鍵部屋・オープン部屋で、プレイヤー状態やホストの記録を共有 |
| カスタム演出 | ラウンドとテラーに応じた画面枠の色を設定 |
| データ管理 | JSON形式のバックアップ、復元、履歴の保存上限、手動編集 |

PCとスマートフォンの画面幅に対応しています。

## 使い方

### 1. ページを開く

リポジトリをダウンロード・解凍し、`index.html` をブラウザーで開いてください。通常の利用にビルド作業やNode.jsのインストールは必要ありません。

`index.html` と `assets` フォルダーは、同じフォルダーに置いてください。

### 2. ゲーム連携アプリを起動する

ゲームの情報を自動表示するには、対応するWebSocket形式のデータを送信する**別途のゲーム連携アプリ**が必要です。このリポジトリにはブラウザー側の画面が含まれます。

標準の接続先は次のとおりです。

```text
ws://localhost:11398/
```

接続先を変える場合は、画面右上の「データ管理」から「ゲーム連携の接続先」を設定し、「保存して再接続」を押してください。

`localhost` はページを開いている端末自身を指します。別端末から利用する場合は、連携アプリ側の対応と接続先の設定が必要です。

### 3. 記録とメモを確認する

- ラウンド終了時に、受信した情報から戦績と履歴を記録します。
- 出現中のテラー名やテラー別統計の名前を押すと、攻略メモを開けます。
- Wikiのリンク先が合わない場合は、メモ画面の「このテラーのWiki URL」に正しいURLを指定してください。
- カウンターや履歴を訂正する場合は「編集モード」をONにしてください。

## マルチプレイ連携

「マルチプレイ連携」から表示名を入力し、部屋を作成・参加します。

- **鍵部屋**：ホストが設定した部屋IDとパスワードで参加します。生存状態、タグ、部屋参加中の戦績を共有できます。
- **オープン部屋**：インスタンスIDを使って部屋を作成・検索します。参加者は匿名の閲覧者として扱われます。
- **共有記録**：ゲストはホストの特殊ラウンド履歴とランプ状態を確認できます。個人の保存データとは別に表示します。

マルチプレイにはインターネット接続が必要です。匿名参加は一覧への非表示を意味し、通信相手に対する完全な匿名化ではありません。

## 保存とバックアップ

記録や設定は、利用しているブラウザーのローカルストレージに保存します。

- 「データ管理 → データをエクスポート」でバックアップできます。
- 「データ管理 → データをインポート」でバックアップを復元できます。復元時は現在の記録を置き換えます。
- 別のブラウザー・端末・公開URLに移る場合は、エクスポートとインポートでデータを移してください。
- ブラウザーのサイトデータを削除すると保存記録も消えるため、必要な記録はバックアップしてください。

履歴の手動編集は、累計戦績や最高連勝を自動で再計算しません。必要に応じてカウンターも編集してください。途中で通信が切れたラウンドは、結果を確認できないため集計せず、次のラウンドから記録を再開します。

## ファイル構成

```text
.
├── index.html          # 画面の構成
├── README.md           # この説明
└── assets/
    ├── css/            # デザイン・画面幅への対応
    ├── data/           # テラー名とWiki URLの対応表
    └── js/             # 保存・集計・メモ・接続などの処理
```

Wikiの対応表は `assets/data/wiki-links.js`、色やレイアウトは `assets/css/style.css` にあります。

## 接続できない場合

ゲーム連携アプリの起動、接続先、ブラウザーの接続許可を確認してください。HTTPSで公開したページからローカルの連携先への接続は、ブラウザーの制限を受ける場合があります。まずダウンロードした `index.html` で確認してください。

実ゲームとの接続や別PC間の通信は、利用環境での動作確認が必要です。
